1.ProducerConsumer using threads in java :
The program implements the Producer-Consumer problem using two threads that share a common ProducerConsumer object. The Producer thread generates numbers starting from 1 and calls produce_item() to store each number in the shared buffer, while the Consumer thread calls consume_item() to read the produced number. In the ProducerConsumer class, the synchronized keyword ensures that only one thread accesses the shared methods at a time. The status variable is used to check whether the buffer contains an item or is empty. If the buffer already contains an item, the producer waits using wait(), and if the buffer is empty, the consumer waits. After producing or consuming an item, notify() wakes up the waiting thread. Thus, the program allows the Producer and Consumer to communicate safely while sharing the same buffer.

Logic:PRODUCER ↓ Creates item ↓ ProducerConsumer BUFFER ↓ Stores item temporarily ↓ CONSUMER ↓ Consumes item

Basic Rules: Buffer contains item → Producer waits Buffer is empty → Consumer waits Producer adds item → Consumer can proceed Consumer removes item → Producer can proceed notify() → Wakes up the waiting thread

2.Matrix Multiplication of 2 matrices by threads :
This program performs matrix multiplication using multiple threads in C++. It creates two 100 × 100 matrices, A and B, and stores the result in matrix C. The program uses POSIX threads (pthread) and creates one thread for each element of the result matrix. Each thread calculates one element of C by multiplying one row of A with one column of B. The matrices are filled with random values from 0 to 9. After all threads finish, the program displays the top-left 5 × 5 part of the matrices. It also checks C[0][0] using normal matrix multiplication to verify the thread result.

Working :-
The program first creates and fills matrices A and B with random values. It then creates 10,000 threads because matrix C contains 100 × 100 elements. Each thread receives a row and column number through ThreadData and calculates one particular element of C. For example, the thread responsible for C[0][0] multiplies all values in row 0 of A with the corresponding values in column 0 of B and adds them together. After creating all the threads, the main program waits for every thread using pthread_join(). Once all threads finish, the program displays part of the matrices and checks one result to make sure the multiplication is correct.
